Политика конфиденциальности

EcoService Bot — внутренний инструмент сервиса по ремонту бытовой техники. Им пользуются только сотрудники сервиса.

Какие данные обрабатываются

  • Данные сотрудников: имя и идентификатор в Telegram, телефон, роль.
  • Данные заказов: имя, телефон и адрес клиента, сведения о технике и неисправности, суммы, фотографии техники.

Данные используются только для выполнения заказов и внутреннего учёта сервиса.

Доступ к Google Диску

Бот запрашивает у владельца сервиса доступ к Google Диску с ограниченным разрешением drive.file: бот может создавать папки и загружать в них фотографии заказов и видит только файлы, которые создал сам. Доступа к остальным файлам на Диске у бота нет.

Данные, полученные через API Google, не передаются третьим лицам, не используются для рекламы и не применяются для обучения моделей искусственного интеллекта. Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Хранение и удаление

Данные хранятся в базе бота на сервере сервиса и на Google Диске владельца сервиса. Владелец может в любой момент удалить файлы на Диске и отозвать доступ бота в настройках аккаунта Google: myaccount.google.com/permissions.
