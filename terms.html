Условия использования

EcoService Bot — внутренний инструмент сервиса по ремонту бытовой техники. Доступ предоставляется только сотрудникам сервиса по приглашению и может быть отозван администратором в любой момент.

Сотрудники используют бота только для работы с заказами сервиса и не передают данные клиентов третьим лицам.
