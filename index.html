EcoService Bot

Внутренний Telegram-бот сервиса по ремонту бытовой техники. Помогает сотрудникам вести заказы: приём заявок, назначение мастеров, статусы ремонта, фотографии техники и учёт оплат.

Бот не предназначен для публичного использования — доступ к нему есть только у сотрудников по одноразовым приглашениям.

Бот сохраняет копии фотографий заказов на Google Диск владельца сервиса. Подробнее — в политике конфиденциальности.
